# PT Citra Buana Prakarsa - Modern Web Portal

Modern rebuild of the official website of **PT Citra Buana Prakarsa (CBP Group)**—the pioneer of master-planned communities in Batam, Indonesia since 1988.

Built with **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

---

## 🌟 Highlights

- **Master-Planned Architecture Showcase**: Flagship coverage for *Union Square Batam (37-Storey Twin Tower)*, *Harbour Bay Downtown*, *Nirup Island Private Luxury Eco-Resort*, *Menara Aria Office Tower*, *Horizon Industrial Park*, and *Swiss-Belhotel*.
- **Interactive Experiences**:
  - Hero Slider with smooth animations and multi-layer gradient depth.
  - Category filters (Mixed-Use, Commercial, Hospitality, Industrial, Eco-Luxury) with instant client-side search.
  - Interactive Consultation & Schedule Viewing form.
  - High-res project detail pages with specs, amenities checklists, and galleries.
- **Modern Typography & Brand Palette**:
  - Luxurious Serif & Sans pairing.
  - CBP Navy (`#0b1626`) & Gold (`#c5a770`) signature brand identity.
- **Responsive & High-Performance**: Optimized for mobile, tablet, and desktop viewports.

---

## 🛠 Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS with custom CBP brand theme
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Language**: TypeScript

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm start
```
